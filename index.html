      About DialectDrift

      DialectDrift translates ordinary sentences into regional dialects to reveal the linguistic fingerprints of American English.

      Data & Methodology

      Data originates from the Harvard Dialect Survey and regional vocabulary datasets. Audio visualizations are dynamically generated using browser Web Audio APIs directly from text-to-speech waveforms (OpenAI TTS-1 model). Word clouds and maps utilize D3.js to visualize the geographic boundaries and intensity of these linguistic quirks.

      Tools Used

      • HTML5 / CSS3 / Vanilla JS
      • D3.js & TopoJSON for mapping
      • d3-cloud for word clouds
      • Web Audio API for real-time acoustic analysis
